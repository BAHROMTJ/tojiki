# Contributing

Thanks for helping improve Tajik language tooling! Native speakers and linguists are especially welcome — many fixes need language knowledge more than code.

1. Fork the repository and create a branch.
2. Add or update tests in `tests/` for any change.
3. Run `python -m unittest discover -s tests` (from the project root with `PYTHONPATH=src`, or after `pip install -e .`).
4. Open a pull request describing the change. Issues may be written in English, Tajik or Russian.

Good first issues are labeled `good first issue`. If you notice a wrong number word or transliteration, please open an issue with the correct form and, if possible, a source.
